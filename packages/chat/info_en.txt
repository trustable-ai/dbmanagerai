?What is the serverless engine used by Nuvolaris?

Nuvolaris uses Apache OpenWhisk as its serverless engine, providing
asynchronous, event-driven function execution at scale.

?How does Apache OpenWhisk work?

OpenWhisk uses Kafka as a message queue and load balancer to distribute
workloads to invokers running in Docker containers. It processes stateless
actions triggered by events, ensuring scalability and fault tolerance.

?What are the components of the OpenWhisk architecture?

The main components are Nginx (reverse proxy), Controller (auth and routing),
Load Balancer (task assignment), Kafka (message queue), Invokers (Docker
executors), and CouchDB (metadata store).

?What does the Controller do in OpenWhisk?

The Controller authenticates and authorizes requests, enriches them using
CouchDB data, and sends them to the Load Balancer.

?What is the function of the Load Balancer in OpenWhisk?

It distributes actions to invokers based on resource availability. If necessary,
it queues requests in Kafka until execution resources are available.

?What is an Invoker in OpenWhisk?

An invoker executes actions inside Docker containers, initializes runtime
environments, captures logs, and stores results in CouchDB under an activation
ID.

?How are results retrieved in OpenWhisk?

Clients receive an activation ID for asynchronous calls or wait synchronously
for immediate results, both retrievable via CouchDB.

?Why are OpenWhisk functions stateless?

Stateless design ensures scalability and avoids synchronization issues,
offloading persistent data to external storage like NoSQL databases.
