Chat Message Handling Specification

When the user types something in the chat input field and presses Enter or clicks the submit button, the application should:

1. Collect Message History

Search the page for all divs generated by previous user messages or assistant responses
Build a messages array with objects in the format:

json  {"role": "<role>", "content": "<content>"}

role is "user" for user questions
role is "assistant" for AI responses

2. Send API Request

Make a POST request to $VITE_STREAM/web/truchat/v1/chat
Set Content-Type: application/json

Send payload:

json  {"input": "<user input>", "messages": "<messages array>"}

3. Handle Streaming Response

Read the sequence of chunks from the streaming response
Assume each chunk is a JSON string that needs to be parsed to extract the content
Concatenate the content progressively
Render the accumulated content from Markdown to HTML
Display the rendered HTML in the response div (updating as new chunks arrive)

4. Interruption Control

While the AI is responding, display a "Stop" button at the bottom If the user clicks the stop button, abort the streaming request immediately
